# 流水线设计说明

本项目处理电商葡萄牙语负面评论，目标是在控制大模型成本的同时，提取可供卖家采取行动的具体问题。原始数据共 99,224 条，先按评分筛选出 22,754 条负面评论，再完成文本清洗、空值检查和去重，得到 14,445 条有效评论及 13,555 条非空唯一文本。

我采用“Python 规则 + MiniLM 语义分流 + DeepSeek 结构化抽取”的分层方案，而不是让大模型处理全部评论。Python 规则识别明确表达和简单情感；多语言 MiniLM 在本地生成 384 维向量，与业务类别原型计算余弦相似度，再融合规则信号决定路由。短评、明确规则命中和语义候选不足的评论按路由策略处理，复杂或存在上下文歧义的评论才进入大模型环节。向量保存在 SQLite 中，减少重复编码。

DeepSeek V4.1 Flash 通过 Yeellow 兼容接口输出指定 JSON Schema，包含类别、严重程度、葡萄牙语证据、英文翻译、情感得分、可行动性和置信度。证据必须是原文精确子串；订单取消疑问不直接等于配送延迟；只有包装本身明确物理破损才标记为 packaging。LLM 结果独立缓存，失败单独记录。本次完成全量前处理与语义分流，并进行小规模 API 验证；全量 LLM 抽取尚未执行。
