# 准确率评估方法与结果

## 一、评估方法

使用 30 条人工审核评论作为参考标准，将人工标注的多标签业务类别与同一批评论的 Python + MiniLM 候选类别进行逐条比较。人工标注文件为 `ground_truth_30_v1.0.csv`，预测文件为 `rule_predictions_30_v1.2.csv`。两份文件按 `review_id` 对齐，30 条 ID 全部匹配且无重复。

本次评估对象是 Python + MiniLM 分流阶段，不是 DeepSeek。原因是 DeepSeek 只完成了小规模 API 集成测试，没有在这 30 条样本上形成完整、可对照的 LLM 预测集。

## 二、整体结果

| 指标 | 结果 |
|---|---:|
| 样本量 | 30 |
| Micro Precision | 87.50% |
| Micro Recall | 23.33% |
| Micro F1 | 36.84% |
| Macro Precision | 50.00% |
| Macro Recall | 19.95% |
| Macro F1 | 28.33% |
| 完全匹配样本 | 9/30（30.00%） |

## 四、结果解读

本次 Micro Precision 为 87.50%，高于 Micro Recall（23.33%），说明当前规则与 MiniLM 候选生成偏保守：模型提出的候选大多有人工标签支持，但漏掉了部分真实问题。尤其是 `missing_item`、`other` 和部分 `wrong_product`、`quality_defect` 样本没有被充分召回。后续应优先检查候选阈值、规则覆盖范围和类别原型表达，而不是简单降低所有类别阈值。

## 五、评估边界

本次 30 条样本已完成人工审核，适合用作小样本初步评估，但样本量较小，且类别分布不均衡，指标存在较大不确定性。`packaging` 在本批人工样本中没有正例，因此无法评估该类别的召回能力。上述指标只反映规则 + MiniLM 候选阶段，不代表最终 LLM 抽取准确率，也不能外推为全量数据准确率。DeepSeek 全量抽取及 LLM 对照评估尚未完成。
